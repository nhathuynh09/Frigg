# 👩‍🍼 Frigg

## 📖 Description
The *Frigg* is a health care website designed for mothers and babies.  
It provides:
- Product categories to support pregnancy  
- Baby care tips  
- Postpartum meal plans  
- Explanations of traditional practices after childbirth  

👉 The goal is to deliver reliable, accessible, and convenient resources to help mothers take care of themselves and their babies.

---

## ✨ Features
- Display categorized health products for pregnancy and baby care  
- Search and filter content easily  
- Baby care tips and postpartum nutrition guides  
- Simple login/register form (simulation, will be upgraded later)  
- Informative articles about traditional mother care practices  

---

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript, React
- **Data Storage:** Static JSON files for sample content  
- **Version Control:** Git + GitHub for collaboration and history tracking
